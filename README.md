# FocusBoard WeApp

FocusBoard WeChat mini-program companion app (Taro) for the Flutter FocusBoard project.

## Overview

A WeChat mini-program built with Taro that mirrors the FocusBoard productivity experience (Kanban + Eisenhower Matrix) on mobile.

## Getting started

```bash
npm install
npm run dev:weapp
```
